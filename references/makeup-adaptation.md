# 按人物结构与本轮目标适配妆容

本规则融合南鸢 v0.2.1，区别底层人物、妆面与拍摄；来源及许可见 THIRD_PARTY_NOTICES.md。

## 先选择目标，再选产品形容

先确定要保留圆润、增加横向感、形成向上视觉、柔化锐感，还是表现反差。圆/长脸不是缺陷，不自动显瘦或缩短；强度、妆容设计、修图程度和基础肤色分别控制。

关键控制写清部位、色相、落点/范围、线条/方向、质地/边缘、强度。默认选眼/唇/双颊中的一个重点；多重点妆按用户要求处理。淡妆、日常妆、浓妆可沿用 social-style.md 的三档配方，但按脸适配而非每人复制同一句。

| 已有结构/要求 | 适配策略 | 保留边界 |
|---|---|---|
| 圆润脸、保留柔软感 | 双颊中央柔边铺色，可适量横向展开 | 不自动削脸或改颧宽 |
| 偏长脸、增加横向妆感 | 在所选腮红落点内横向组织颜色 | 不宣称物理缩短脸 |
| 单眼皮/内双/遮盖褶皱 | 按睁眼后的可见上眼睑区域安排眼影和贴根线 | 不编造褶皱、不直接改眼型 |
| 天然上扬眼尾、柔化锐感 | 较短平直细眼线、外侧边缘更柔和 | 天然眼角保持上扬 |
| 天然下垂眼尾、增加上提视觉 | 外侧睫毛或眼线局部轻提 | 不把原生眼角记成上扬 |
| 薄唇、只涂唇釉 | 沿天然边界控制色彩与中央反光 | 不自动描成厚唇 |
| 中深/橄榄底调肤色 | 按原肤色调节可见色彩、透明度和局部反光 | 不自动提白；清透不等于冷白 |
| 柔和骨相、希望利落 | 选眉尾或唇缘一个重点略加强 | 不提高眉骨、削尖下巴 |

妆的局部水光不是全脸油光。不要为了真实感默认增加雀斑、油脂、干燥纹或摄影颗粒；不要为了修图让不同人物变成同一套五官。

## 固定脸换妆

锁定已知骨架、软组织、眼鼻唇和基础肤色，保留痣与发际线。用户仅改唇色时，保留光泽、唇缘、覆盖方式和其余妆容；用户改眼线柔度时，只处理当前线条的锐度/强度。原稿未说明的眼窝或面中深度继续不说明。

## 同一套妆，换不同的人

先固定六项可比较合同：`base` 底妆覆盖/质地，`eyes` 眼影色彩/铺色逻辑，`liner` 眼线粗细/方向，`lashes` 睫毛状态，`blush` 腮红色彩/相对落点，`lips` 唇色/质地/边缘。

每人完整 prompt 展开同一段妆容合同，逐项内容保持一致。只在段后解释覆盖面积与相对坐标的适配，不能将另一人的平直眼线改翘尾、中央腮红改斜扫、缎光唇改果冻唇。风格预设只能调整其允许的拍摄和修图层，不能覆盖这套共同妆容。

“同妆”与“按脸重新设计一套妆”是不同任务。后者允许改变线条和落点，前者只允许比例/面积适配。两者均不能用妆容变化冒充不同脸。
