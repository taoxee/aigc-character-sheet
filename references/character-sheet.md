# Character reference sheet：最终交付模板

仅在已认可人脸、服装输入/无输入已确定后执行。它是标准工作流最终产物；不把所有单张人像都做成拼图，也不自动接视频。

## 输入角色与身份

Image 1 为已认可的原始人脸 identity_anchor，控制脸型、五官、发际线、肤色、年龄与标记。用户上传服装时，Image 2 仅负责服装/配件，参考图里的人脸与身材不能覆盖身份。已有设定表修订时，将旧表作为额外编辑目标，仍保留原始身份图。

实际传入图片，使用本地图前先查看。不要仅在文字中称“同一个人”却不提供真实图像输入。新人物不默认传入包内案例的脸。

服装分支：

- provided：提取明确可见的款式、版型、主色、材质、层次、袖长、领口、裤/裙长、鞋与已提到的设备；同一搭配贯穿三视图和表情。不可见背面细节可作合理设计补全，但不能声称已由照片确认。
- none：保留已选人物的可见服装，或按人物用途补全简洁搭配；说明新增下装、鞋、身体/侧背设计。不要默认所有人都是蓝衣白裤。没有提到设备就不凭空增加手机、包、武器或首饰。

## 默认白底排版

2:1 横版、纯白背景、舒适留白与浅灰细分隔线，无文字、数字、署名、标志、水印或账号。不要用印在图上的标签来弥补混乱布局。

- 左约45%：等高、同基线的全身正面、真实90°侧面、背面三视图，头顶与脚完整，身体和服装比例统一，站姿放松、双臂略离躯干。
- 右约55%：三列两行、同尺度的六个人脸特写，脸足够大，看得清眉眼口部变化，不把六张塞进旧四格造成过小。
- 下方：服装领口/面料、袖口/下摆、下装或鞋的必要细节；配色块对应真实出现的主色、肤色、妆色。默认约七色，可按人物服装调整，不伪造已测量的色值。

正面和六表情保持正头直视；侧面和背面按其真实方向，不回头看镜头。保持用户选中的自然/日韩/复古等风格，不因排成设定表而换成动漫、绘画或过度写实。

## 六种默认表情（阅读顺序）

1. 平静：眉颊放松、嘴唇轻合、稳定目光。
2. 浅笑：嘴角轻抬、少量颊部响应，微露一窄条上牙。
3. 开心大笑：笑幅明显比浅笑大，上牙可见、面颊抬起、下眼睑轻压，双眼仍自然睁开。
4. 惊讶：眉毛抬起、上眼睑更打开、嘴呈小O形，不夸张放大眼睛。
5. 轻微不满：眉头略压低并收拢、下眼睑微紧、嘴唇轻压，无笑意。
6. 难过：内眉略抬、外眉放软、嘴角微垂，克制低落；不靠大滴泪水或花妆替代表情。

必须改变肌肉配置，不是六张差不多的微笑。脸部结构、年龄、发色、妆容、痣和曝光保持一致，不能通过换脸或换妆制造区别。表情属于同一人物变体，不使用 distinct 阵容门槛故意拉开骨相。用户明确指定其它表情或数量时遵从，不额外生成无关变体。

## 可复用完整 Prompt

花括号在执行前按当前人物填写，原始脸与服装通过实际图像输入提供。

```text
以图片1中已认可的成年虚构人物为身份参考，制作一张正式设定资料风格的 Character reference sheet。保持其实际脸部结构、五官比例、自然不对称、年龄、基础肤色、发际线、发型与已有标记，妆容和修图程度沿用已选方向：{人物风格与妆容}。{各输入图片的明确角色}。
服装：{用户提供的服装，或明确选择无输入后补全的搭配}。三视图、表情和细节中的领口、袖长、下摆、裤裙、鞋及设备一致；不增添未提到的设备或配件。
纯白背景、2:1横版、整齐网格、浅灰细分隔线。左侧约45%排全身正面、真实90度侧面、背面，等高同基线，头和脚完整、站姿自然。正面头部端正直视镜头；侧面与背面保留其真实方向，不回头看相机。
右侧约55%为三列两行的六个人脸特写，同尺度、同光线、同一张脸；全部正头、双眼自然睁开直视镜头。依次是平静、浅笑、开心大笑、惊讶、轻微不满、难过。平静放松眉颊闭唇；浅笑微露上牙；大笑明显抬颊露牙、与浅笑拉开幅度；惊讶抬眉、嘴小O形；不满略皱眉、压唇而不笑；难过内眉略抬、嘴角微垂，不靠大滴泪水。表情通过眉眼、面颊和嘴部变化实现，不改五官身份、妆容或发型，不歪头。
下方整理服装面料、领口、袖口下摆与下装/鞋的必要细节，并排布{约七个与实际设计一致的配色块}。脸部特写优先清楚可辨，分区不重叠、不裁掉头脚。维持所选风格的摄影质感与干净肤色，无颗粒、灰褐斑驳或重复细纹覆盖。整张图无任何可见文字、数字、标签、手写署名、水印、标志或账号。
```

## 出图检查与收尾

核对三视图朝向和同一服装；恰好六表情且能区分；身份一致、头不歪、正面目光对镜头；必要细节和色板齐全；白底无字、无水印。精确比例和输出像素只记录实际工具结果，不因 prompt 写了就声称已达到。

六表情并非六个新角色。检查器只用于相关身份/文字目标，不将侧背视图套进“每一格都直视镜头”的单人合同。需要修正时只调整错误的表情/布局/衣服，不重新设计脸。

交付最终设定表与实际 prompt，保留原始身份图和服装来源，即完成本工作流。样例与精确执行记录见 [已认可设定表](approved-character-sheet.md)。
