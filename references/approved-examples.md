# 已认可的三份实际成图

2026-11-11，用户在查看三位骨相不同、分别对应自然日常/日韩轻修图/复古风格的人像后，反馈“效果不错，固化下来”。因此保留本次成图、人物设计与精确 prompt 作为可复用样例；没有将所有风格合成一个默认。

仅在需要时读取对应一个样例，不必同时加载全部 prompt 和图片：

- [自然日常](looks/natural-daily.md)：短方圆轮廓、单眼皮，克制日常妆、微露上牙；适合自然生活感的起点。
- [日韩轻修图](looks/soft-social.md)：收束轮廓、较开放的眼型，轻修图缎光、浅腮红与薄唇釉；适合精致而克制的社交照片方向。
- [复古](looks/vintage.md)：偏长轮廓、较明确颧鼻层次，横向腮红、复古红唇和波浪发；是一种创作方向，不是严格年代复原。

PNG 与完整性清单位于 `../assets/approved-portraits/`，相对本文件；清单为 manifest.json。图片内无可见文字或署名，文档元数据中的标题/角色 ID 不进入画面。

## 固化哪些内容

保留通过本次视觉检验的摄影质感、干净肤色组织、骨相与妆容分层方法，以及正头、直视、无文字水印约束。每个样例的年龄、五官、发型与服装只属于该角色，不是未来所有人物的默认值。

- **从零设计：** 读取所选样例的风格/肤质/光线语言，重新设计人物骨相。不能把其中一张图作为所有新人物的身份锚点。
- **复用同一个人：** 用户选中具体样例时，先查看对应 PNG，再作为真实图像输入。身份由该张实际图片确定，原设计中没完全实现的结构不能在复用时悄悄“纠正”而改脸。
- **换风格/妆容：** 保持已选人物身份，再替换表现层。三张是三个不同的人，不是同一人的风格强度标尺，不能当作受控前后对比。

程序轴是创作目标，图片是可见结果；两者有差异时保留原始记录和说明。原有下颌柔化、眼睑/唇面差异已写在对应样例中。用户整体认可不代表每个骨相细节都被精确实现。

## 复用边界

这些样图仅验证了三个静态结果，不承诺重新运行同一 prompt 会得到同一张脸，也未验证跨场景、说话牙齿或视频时间一致性。复用人物始终引用其图片，后续实际结果逐张核对。
